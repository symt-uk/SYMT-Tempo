# Contributing to SYMT Tempo

Thank you for helping improve SYMT Tempo Community Edition.

1. Open an Issue before major changes; avoid posting confidential project/client names or time records.
2. Fork the repository for review and submit a focused pull request with a clear description and manual Windows test steps.
3. Do not commit generated `Data/`, logs, actual timesheets, credentials, binaries, or commercially licensed dependencies.
4. No external dependencies should be added without a licence review. Windows PowerShell 5.1 and .NET WinForms remain the primary runtime.
5. By opening a pull request, you accept the contribution grant in section 4 of `LICENSE.txt` and confirm the contribution is yours or you have permission.
6. Do not publish unofficial binary distributions or reuse SYMT branding without permission.

**Important:** contributions are welcomed, but this is a source-available project, not an OSI-approved open-source project. Contributions are reviewed at SYMT Limited's discretion.
